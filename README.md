# 📊 Mobile Sales Intelligence Dashboard
### Revenue & Customer Behavior Analysis | Power BI

---

## 📌 Project Overview
Developed an end-to-end Power BI dashboard to analyze 
mobile sales data, customer behavior, and regional performance.

---

## 🎯 Key Achievements

- 🔄 **Data Transformation** — Used Power Query to clean 
  and model data from multiple sources

- 📈 **Advanced DAX** — Implemented Time Intelligence 
  functions (MTD, Same Period Last Year) to track 
  growth and performance trends

- 🎨 **Interactive UI** — Designed user-centric interface 
  with custom navigation buttons and slicers 
  for seamless exploration

- 💡 **Business Insights** — Visualized payment trends 
  (UPI vs Cards) and linked delivery speed 
  to customer rating scores
